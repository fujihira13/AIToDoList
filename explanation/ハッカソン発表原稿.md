## スライド3：ソリューション紹介（40秒）

### スライド内容
```
💡 Eisenhower Board とは？

アイゼンハワーマトリクス × AI表情生成

┌─────────────┬─────────────┐
│  🔥 重要×緊急  │  🧠 重要×非緊急 │
│   今すぐやる   │   計画的に     │
├─────────────┼─────────────┤
│  ⚠️ 非重要×緊急 │  🌿 非重要×非緊急│
│   誰かに任せる  │   手放す      │
└─────────────┴─────────────┘

👤 担当者の表情がタスクの緊急度で変わる！
```

### 発表文言
> 「Eisenhower Boardは、アイゼンハワーマトリクスという
> 時間管理のフレームワークをベースにしたタスク管理アプリです。
> 
> タスクを『重要度』と『緊急度』の2軸で4つの象限に分類します。
> 
> そして、このアプリの一番の特徴は...
> 
> タスクの象限に応じて、担当者のアバター表情が自動的に変わること！
> 
> 緊急タスクを抱えている人は怒った顔に、
> 余裕がある人はリラックスした顔になります。
> 
> 一目で誰が忙しいか、誰に仕事を振れるかが分かるんです。」

## 🎤 発表のコツ

### 時間配分のポイント
- **デモは1分以内**に収める（長いと飽きられる）
- **最初の30秒で興味を引く**（課題提起が重要）
- **技術の説明は簡潔に**（詳細は質問があれば答える）

### 話し方のポイント
1. **ゆっくり、はっきり話す** - 緊張すると早口になりがち
2. **聴衆を見る** - スライドばかり見ない
3. **具体例を入れる** - 「こんな経験ありませんか？」と共感を誘う
4. **デモは事前に何度も練習** - トラブル時のリカバリーも準備

### トラブル対策
- デモが動かない場合 → スクリーンショットを用意
- 時間オーバーしそう → 技術スタックを省略
- 質問が来たら → 分からないことは正直に「調べます」
